# Product Overview

## 서비스

치씨티비(ChCTV)는 치지직의 대규모 합방/RP 콘텐츠를 더 쉽게 탐색하고, 원하는 방송을 선택해 여러 개를 함께 시청하도록 돕는 비공식 멀티뷰 서비스다.

## 현재 MVP 범위

현재는 배포 가능한 랜딩 페이지와 MVP 기반 단계다. CHZZK API 연동, 실제 멀티뷰, 로그인은 아직 포함하지 않는다.

## 제품 방향

- 사용자가 여러 방송을 동시에 시청할 수 있다는 가치를 먼저 이해하게 한다.
- 탐색부터 선택, 멀티뷰 시청까지의 흐름을 끊기지 않게 설계한다.
- 멀티뷰 UX를 브랜드 장식보다 우선한다.

UI/UX 공통 규칙은 [디자인 시스템](../design/design-system.md)을 따른다.
